# 🇩🇪 B2 Voice Buddy - By Arbab Khan

**From Gujranwala to Germany!**

An AI tool to practice German B2 speaking.

### Features:
- Converts Roman Urdu / English to German B2 level
- Gives German voice output for speaking practice
- Made with Python, gTTS, Gradio
